# Society Simulation

A town of individuals with their own preferences, an economy, and a government you can rewrite in plain English.

Work in progress. See [docs/DESIGN.md](docs/DESIGN.md) for the architecture.

- `sim/` — the simulation core (Rust, compiled to WebAssembly for the browser).
- `web/`, `server/` — the browser client and the law-drafting endpoint (not yet built).
- `reference/prototype/` — an earlier JavaScript prototype kept for reference during the port.
